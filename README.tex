\section*{How to Use This Template}
\addcontentsline{toc}{section}{How to Use This Template}

This LaTeX template is designed to help students prepare a structured and professional coursework report. The project is organized into multiple files to improve readability, collaboration, and ease of editing.

\subsection*{File Structure}
\begin{itemize}
    \item \texttt{main.tex} : Main file (compile this file only)
    \item \texttt{motivation.tex} : Introduction / Motivation
    \item \texttt{methods.tex} : Methodology
    \item \texttt{results.tex} : Results
    \item \texttt{conclusion.tex} : Conclusion
    \item \texttt{appendix1.tex} : Appendix (additional materials)
    \item \texttt{Bibliography.bib} : Reference database
\end{itemize}

The main document includes each section using the \texttt{\textbackslash input\{\}} command.

\subsection*{Document Specifications}
\begin{itemize}
    \item Document class: article
    \item Font size: 12pt
    \item Paper size: letterpaper
    \item Margins: 1 inch on all sides
    \item Page numbering: bottom center
    \item Footer: includes latest compilation timestamp
\end{itemize}

\subsection*{How to Write Your Report}
Students should complete each section in its respective file:
\begin{itemize}
    \item \textbf{motivation.tex}: Background, problem statement, and objectives
    \item \textbf{methods.tex}: Data, models, and methodology
    \item \textbf{results.tex}: Tables, figures, and findings
    \item \textbf{conclusion.tex}: Summary and interpretation
    \item \textbf{appendix1.tex}: Additional materials such as code or extended analysis
\end{itemize}

\subsection*{References}
All references should be stored in \texttt{Bibliography.bib}. Use the command \texttt{\textbackslash cite\{\}} to cite sources in the text. The template uses a numeric citation style.

\subsection*{Compilation}
Compile the document using the following sequence:
\begin{center}
\texttt{pdflatex → bibtex → pdflatex → pdflatex}
\end{center}
Alternatively, you may use an online platform such as Overleaf.

\subsection*{General Guidelines}
\begin{itemize}
    \item Keep the report clear, concise, and well-structured
    \item Include only relevant figures in the main text
    \item Place supplementary materials in the appendix
    \item Ensure all sources are properly cited
    \item Follow academic integrity guidelines
\end{itemize}

This template provides a consistent and professional framework for coursework submission.
